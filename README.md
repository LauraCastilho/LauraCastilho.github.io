# Portfolio 💼

This project is my personal portfolio website, built with ReactJS, TypeScript, Tailwind CSS and shadcn-ui to showcase my experience, skills and projects as a Full Stack Developer.

🔗 [Live demo](https://lauracastilho.github.io)

## 🚀 Getting Started

First of all, you need to have node and pnpm installed on your machine. Then you can clone the repository.

```bash
git clone https://github.com/LauraCastilho/LauraCastilho.github.io.git
cd LauraCastilho.github.io
pnpm install
pnpm dev
```

## 💻 Technologies

- Vite
